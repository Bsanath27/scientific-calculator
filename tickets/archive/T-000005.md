## Goal
SymbolicEngine.evaluate() uses DispatchSemaphore to block and wait for an async Task. If called from the main thread this can deadlock. Remove the semaphore pattern; either remove the sync path or use a proper detached Task approach

## Acceptance Criteria
- [x] Remove DispatchSemaphore from SymbolicEngine.
- [x] Refactor Dispatcher and ViewModels to use evaluateAsync.
- [x] Add verification tests for deadlock avoidance.
